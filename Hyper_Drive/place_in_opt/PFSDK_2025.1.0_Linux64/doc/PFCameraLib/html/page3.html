C++ Samples

The examples folder contains the following samples:

  • ConfigAndGrab_Console_Asynchronous.cpp
    This example is a command line application that shows the generic process to discover the cameras in the computer or network, connect to a camera, grab images by registering a callback, and disconnect.
  • ConfigAndGrab_Console_Color_Context.cpp
    This example is a command line application that shows the generic process to discover the cameras in the computer or network, connect to a double rate camera, grab images, demodulate images, debayer images and save images to disk files.
    After finish the camera is disconnected. This sample uses an ImageTransformationContext to optimize the debayering process.
  • ConfigAndGrab_Console_Events.cpp
    This example is a command line application that shows the generic process to discover the cameras in the computer or network, connect to a camera, register listener to receive events from Message channel, grab images and disconnect.
  • ConfigAndGrab_Console_Online_DR.cpp
    This example is a command line application that shows the generic process to discover the cameras in the computer or network, connect to a double rate camera, grab images, demodulate images, save images demodulated to files
    and disconnect the camera.
  • Console_Offline_DR_OpenCV.cpp

    This example shows the generic process to demodulate an image captured previously with double rate camera and saved to ".BMP" file. The image is demodulated with PFImage class and saved to file. See related sample ConfigAndGrabConsole_Online_DR to verify how capture double rate images.
  • ConfigAndGrab_Console_OpenCV.cpp
    This example is a command line application that shows the cameras available, connect to a camera and displays the image received from the camera to a window.
    This sample uses OpenCV to display the image on a Window.
  • ConfigAndGrab_Console_SoftwareTrigger.cpp
    This example is a command line application that shows the generic process to discover the cameras in the computer or network, connect to a camera, grab images using a software trigger, and disconnect.
  • ConnectConfigAndGrab_Console.cpp
    This example shows how to connect to a camera with different connection parameters, such as IP address or MAC address.
    After the camera is connected, it shows how to configure the camera features and grabs images until the 'space' key is pressed. Then, the camera is freezed and disconnected.
  • Console_Advanced_Asynchronous.cpp
    This example is a command line application that shows a more advanced and explicit process of performing image acquisition. The API presented enables finer grained control which allows better resource reuse and faster AcquisitionStart/AcquisitionStop cycles.
  • Console_SoftwareTrigger_Asynchronous.cpp
    This example is a command line application that shows the generic process to discover the cameras in the computer or network, connect to a camera, grab images using a software trigger, and disconnect.
  • DiscoverConfigAndGrab_Console.cpp
    This example is a command line application that shows how to discover the available cameras in the system or network and how to connect a selected camera.
    Once connected, it shows how to configure the camera features and grabs images until the 'space' key is pressed.
  • LoadAndSaveConfigurationFile_Console.cpp
    This example uses a configuration file to connect to a camera and after setting some parameters it saves the current camera configuration to a file.
