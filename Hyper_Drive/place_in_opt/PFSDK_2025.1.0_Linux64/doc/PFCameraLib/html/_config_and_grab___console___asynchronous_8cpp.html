Detailed Description

This example is a command line application that shows the generic process to discover the cameras in the computer or network, connect to a camera, grab images by registering a callback, and disconnect.

Description: The main functionality of this example is to show all the available cameras in the computer or network and to connect to a specific one. After that it shows how to configure some of the camera features and grab images until the 'space' key is pressed. Finally the camera is freezed and disconnected.
