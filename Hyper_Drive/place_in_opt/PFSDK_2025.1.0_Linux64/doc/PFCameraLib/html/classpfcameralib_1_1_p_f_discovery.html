Discover GEV and U3V compliant devices.

This function search for all connected devices taking into account ignore_subnet flag.

Parameters
[in]ignoreSubnetSet to true if you wish to ignore subnet network address for GEV cameras (This parameter has no effect for U3V cameras).
[in]portHost side port for GEV discovery. Use 0 to let the OS find a suitable port.
Returns
PFResult
Error Codes: PFSDK_NOERROR
PFSDK_ERROR_DISCOVERY_NO_CAMERAS_FOUND
