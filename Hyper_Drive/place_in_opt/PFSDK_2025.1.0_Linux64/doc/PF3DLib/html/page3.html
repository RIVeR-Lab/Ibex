C++ Samples

The examples folder contains the following samples:

  • 3D03_GetRangeMap.cpp
    This example is a command line application that shows how to configure a 3D03 Camera, grab some frames,
    create a range map and store it as a PLY file.
  • 3D06_MV4_GetRangeMap_StatusLine.cpp
    This example is a command line application that shows how to configure a 3D06 Camera,
    grab some frames, process status line information, create a range map and store it as a PLY file.
  • 3D06_GetRangeMap.cpp
    This example is a command line application to show the cameras available, connect to a 3D06 camera and capture Images.
    It processes the captured images into RangeMaps
  • 3D07_GetRangeMap.cpp
    This example is a command line application to show the cameras available, connect to a 3D07 camera and capture Images.
    It processes the captured images into RangeMaps
  • 3D07_GetRangeMap_StatusLine.cpp
    This example is a command line application to show the cameras available, connect to a 3D07 camera and capture Images.
    It processes the captured images into RangeMaps, saves the captured RangeMaps and shows the status line information.
