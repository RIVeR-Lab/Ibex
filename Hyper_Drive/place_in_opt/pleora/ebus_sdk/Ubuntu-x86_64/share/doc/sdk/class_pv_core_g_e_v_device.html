Detailed Description

Implements a Virtual GigE Vision Device with full CoreGEV support.

Basic Virtual GigE Vision Device setup: For a software streaming channel source:

  • Inherit a class from IPvStreamingChannelSource, implement all virtual pure methods
  • Instantiate an object of your streaming channel source class For a CoreGEV channel source:
  • Instantiate an object of class type PvStreamingChannelSourceCoreGEV Common:
  • Instantiate a PvCoreGEVDevice object
  • Add you streaming channel to your Virtual GigE Vision Device using AddStream
  • Call PvCoreGEVDevice::Start, selecting the network interface to bind to
  • Use PvCoreGEVDevice::GetInfo to set the identify of your Virtual GigE Vision Device
  • At this point your Virtual GigE Vision Device should be available on the network

A more advanced Virtual GigE Vision Device setup:

  • Inherit a class from IPvStreamingChannelSourceCoreGEV
    • Override selected methods
  • Instantiate an object of your streaming channel source class
  • Instantiate a PvCoreGEVDevice object
  • Add you streaming channel to your Virtual GigE Vision Device using AddStream
  • Call PvCoreGEVDevice::Start, selecting the network interface to bind to
    • Your #IPvStreamingChannelSourceCoreGEV::OnCreateCustomRegisters will be called
    • Your #IPvStreamingChannelSourceCoreGEV::OnCreateCustomGenApiFeatures will be called
  • Use PvCoreGEVDevice::GetInfo to set the identity of your Virtual GigE Vision Device
  • At this point your Virtual GigE Vision Device should be available on the network
  • Use PvCoreGEVDevice::GetRegisterMap to directly access the registers or register access callbacks
  • Use PvCoreGEVDevice::GetGVCPStatistics to monitor GVCP statistics
  • Use PvCoreGEVDevice::GetMessagingChannel to fire events on the messaging channel back to the controller

PvResult PvCoreGEVDevice::AddStream ( PvStreamingChannelSourceCoreGEV *  aSource)

Adds a new stream to the PvCoreGEVDevice.

All streams must be added before starting the PvCoreGEVDevice.

Parameters
[in]aSourceInterface to a user-provided source.
Returns
Includes:
  • PvResult::Code::OK on success.
  • PvResult::Code::INVALID_PARAMETER if aSource is NULL.
  • PvResult::Code::STATE_ERROR if the PvSoftDeviceGEV is already running.
  • PvResult::Code::NOT_SUPPORTED if the maximum stream count has already been reached.
