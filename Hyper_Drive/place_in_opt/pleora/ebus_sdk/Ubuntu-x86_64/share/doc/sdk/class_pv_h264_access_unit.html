Detailed Description

H264 access unit interface to a PvBuffer.

A PvBuffer represents a generic buffer with no specific payload type. If the payload type is H264 access unitdata, the user can obtain a pointer to a PvH264AccessUnit buffer interface through PvBuffer::GetH264AccessUnit.

This PvH264AccessUnit pointer is owned by the PvBuffer and does not need to be released after use. It is valid as long as the PvBuffer exists.
