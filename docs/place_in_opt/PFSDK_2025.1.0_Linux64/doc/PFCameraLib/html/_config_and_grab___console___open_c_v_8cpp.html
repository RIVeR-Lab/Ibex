Detailed Description

This example is an application in command line to show the cameras available, how to connect with the selected camera and show a window with the images from the camera.

OpenCV library is used to display the images.

Description: The main functionality of the example is to show the grayscale images from the camera using OpenCV libraries. The example shows how to capture the raw data coming from the camera and how to display the image.

First, all the cameras are shown in command line together with the properties of the all cameras discovered. The next step is to connect with the camera selected. Then the camera starts grabbing, and the specific information for each frame is displayed: image counter and real time counter in microseconds (time stamp).

In a new window is printed the grayscale image corresponding from the camera connected.

IMPORTANT! OpenCV only use 8 bits (Mono8) or 16 bits (Mono16) to display images.

NOTE: this example does not show color images.

For more information about OpenCV, visit: http://opencv.org
