Windows

When you create your own applications with the pfCameraLib SDK, you must configure your projects so that they are aware of the location of the header files and library files. This page contains:

  • Running C++ Samples
  • Creating a new project C/C++ with Microsoft Visual Studio
  • Configuring paths to your DLLs
  • Running your Applications

Running C++ Samples

  1. Copy the samples from "C:\Program Files\Photonfocus\PFSDK\Samples" to a folder you have write permissions to.
  2. Open any of the samples using Visual Studio 13 or higher.
  3. Build the sample using F7 or the assigned build command key.

Creating a new project C/C++ with Microsoft Visual Studio

  1. Create a C++ project using Visual Studio 13 or higher.
  2. Add \include to the header files path.
  3. Add \lib to the linker libraries path.

Running your Applications

Samples and your applications will run as long as you have the common files PFSDK folder (32-bit or 64-bit) included in the PATH environment variable.
It is also possible to run an application if the eBUS SDK common files are copied to the same folder as the application binary.
