Introduction

PFSDK installs several files into Microsoft Windows system. Although the user may change the installation directory when running the MSI installer, by default it proposes: "C:\Program Files\Photonfocus\PFSDK".

Structure of the Installation Directory

Structure of the installation directory:

  • bin - The main PFSDK binary, DLLs, and precompiled executables of the examples distributed with the SDK. Remember to have these libraries reachable for any program using PFSDK.
  • doc - The PFSDK documentation in HTML and CHM format. Open index.html to start.
  • examples - Visual C++ 2013/2015 example projects using PFSDK (See more information in Examples Distributed)
  • include - Path to be added to the INCLUDE_PATH parameter of your compiler. This directory has the C++ PFSDK API declarations, the internal declarations for the C functions and structures used in the DLLs.
  • lib - Path to be added to the LIBRARY_PATH parameter of your linker. These files will allow the user to link his program to the Photonfocus DLLs.
