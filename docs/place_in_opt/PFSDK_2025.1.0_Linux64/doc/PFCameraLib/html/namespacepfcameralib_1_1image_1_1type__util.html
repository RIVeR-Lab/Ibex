PFCAMERALIB_API int16_t pfcameralib::image::type_util::GetPixelDepth ( pfPixelType  pixelType)

Returns depth associated to each pixel type: e.g: 8 for PixelMono8 , 10 for PixelMono10, 12 for PixelRGB12 and so on.

Note that for color pixel types (3 channels) the function will return the depth for a single channel.
