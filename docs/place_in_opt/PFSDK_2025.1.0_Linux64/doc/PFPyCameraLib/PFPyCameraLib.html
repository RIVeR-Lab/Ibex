GetImage(self: PFPyCameraLib.PFBuffer, image: PFPyCameraLib.PFImage) → PFPyCameraLib.PFResult

This method is called to initialize the image object PFImage. The image pointer used is the one managed by PFBuffer and therefore the image pointer is only assigned. To use this method you have to construct the PFImage using the default constructor. Once the image is loaded it can be manipulated by any other image class method.

Parameters:

Returns:

Error.NONE on success

GetImageCopy(self: PFPyCameraLib.PFBuffer, image: PFPyCameraLib.PFImage) → PFPyCameraLib.PFResult

Get an image object by doing a deep copy.

This method is intended to create an independent PFImage separated from the source image data pointer stored in PFBuffer.

Using this method is discouraged, copying images is both CPU and memory intensive. Whenever you can, call GetImage() for better performance.

Parameters:

image (PFImage) – the image which is going to be initialized with the contents of this buffer.

Returns:

Error.NONE on success

class PFPyCameraLib.PFImage(*args, **kwargs)

This class contains the attributes of a received image and provides methods to convert it to another PixelType or apply one of the BayerFilterType. The image can be stored in a file in different formats, specified in ImageFileType.

Implements the python buffer protocol, in case access to the underlaying data is required.

Overloaded function.

Unpack(self: PFPyCameraLib.PFImage, dest_image: PFPyCameraLib.PFImage, alloc_mem: bool = True) → PFPyCameraLib.PFResult

Unpacks the current PFImage into a new image with the corresponding PixelType.

If the pixel type of the current image is one of the packed modes, this method unpacks the data into a new image with the corresponding unpacked PixelType. For instance from Mono10Packed or Mono10p to Mono10. This method only needs a pointer to the destination image. By default, memory allocation is performed inside this method.

The user can provide a destination PFImage with an already allocated memory buffer. In case no unpack process is performed, for instance because the origin PixelType is Mono8, then DestImage will point to the original image and no memory will be allocated.

Following packed pixel types are supported: PixelMono10p PixelMono10Packed PixelMono12p PixelMono12Packed PixelBayerGB10Packed PixelBayerRG10Packed PixelBayerGB12Packed PixelBayerRG12Packed

Parameters:

  • dest_image (PFImage) – destination image where the current image will be unpacked.

  • alloc_mem (bool) – allocate the memory needed to unpack the image.

Returns:

Error.NONE, Error.ERROR_UNPACK_NOT_PERFORMED.

Return type:

Release (unlock) a buffer which was obtained with a call to GetNextBuffer(). The buffer will be made available for reuse in the ring buffer. Once the buffer is released, its contents may be modified freely by the stream. Do not release the buffer until the data has been retrieved.

PFBuffer.Release() has the same effect and can be used instead.
