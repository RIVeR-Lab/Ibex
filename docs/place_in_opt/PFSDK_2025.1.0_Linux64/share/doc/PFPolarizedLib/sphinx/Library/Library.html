PFPOLCLIB_EXPORT int32_t pfcGenerateDOLPImage_u16(uint16_t *target, uint16_t *result, uint16_t m_originalImageWidth, uint16_t m_originalImageHeight, float start_range, float end_range, pfPixelType pixelType)

Computes Degree of Linear Polarization (DOLP) of the input image and outputs a (width*height) image for MONO camera.

If DOLP is out of a certain range (defined by input parameters stard_range, end_range), its value is automatically set to format max value (for instance, for Mono8 images pixel is set to 255). Pixels out of range will then appear as white pixels.

Parameters:

  • target – [in] Original image buffer with a 2x2 pattern containing 90_45_135_0 polarization angles

  • m_originalImageWidth – [in] Width of the original image

  • m_originalImageHeight – [in] Height of the original image

  • start_range – [in] Defines the beggining of the relative range of valid values (start_range*max_format_val).

  • end_range – [in] Defines the end of the relative range of valid values (end_range*max_format_val).

  • result – [out] Output buffer containing the DOLP image (width x height)

  • pixelType – [in] Sets if pixel is MONO8, MONO10, MONO12 or MONO16

  • m_originalImageHeight – [in] Height of the original image

  • start_range – [in] Defines the beggining of the relative range of valid values (start_range*255).

  • end_range – [in] Defines the end of the relative range of valid values (end_range*255).

  • color – [in] Selects the color to be used to compute AOLPDOLP. MonoHypercube can also be used in this function: color = {Red, Green, Blue, Mono}

  • pixelType – [in] Sets if pixel is MONO8, MONO10, MONO12 or MONO16

  • result – [out] Output buffer containing the DOLP image (width x height)

For color polarized camera only, uses the previously generated pppp_result hypercube to obtain mono images for each polarization angle.

The formula for luminosity is 0.21 R + 0.72 G + 0.07 B (ITU-R BT.709)

  • m_originalImageWidth – [in] Width of the original image

  • m_originalImageHeight – [in] Height of the original image

  • m_angleWidth – [in] Width of the output hypercube (by default m_originalImageWidth/2)

  • m_angleHeight – [in] Height of the output hypercube (by default m_originalImageHeight/2)

  • ppppp_monoresult – [out] Polarized image containing mono images in fromat ppp_monoresult[angle][color]
